\chapter{Reliability, Error Analysis, and the Midterm Workflow}\label{chap:reliability}
\courseweek{Weeks 9--11.} Reliability connects model results to the populations, operating conditions, inputs and risks that produced them.
\begin{learningbox}
\begin{itemize}
\item Segment error by operating condition and retain sample counts.
\item Distinguish a fitted function explanation from a causal claim.
\item Preserve exact data, configuration and an executable evidence trail.
\item Explain choices and failure cases in writing and orally.
\end{itemize}
\end{learningbox}

\section{Weeks 10--11: workflow and examination preparation}
The workflow studio assembles a problem brief, data contract, train/validation/test rule, baseline, metric, error analysis and bounded recommendation. Existing designated Homework requirements remain separate from formative weekly exercises. The written examination checks conceptual understanding. The oral examination asks students to explain choices, interpret a failure case and identify one change that would invalidate a result. Practice notebooks do not replace the written or oral examination.
\begin{checkpointbox}
A model has a strong overall score but fails near a sensor detection limit. State one evaluation slice, one data-collection action and one possible operating restriction. Name the additional evidence needed before recommending that restriction.
\end{checkpointbox}
