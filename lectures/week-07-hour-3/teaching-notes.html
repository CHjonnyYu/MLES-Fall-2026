04. There are several position mechanisms

Timing: 06:00–08:00 (2 minutes).

Teaching intent: The teaching model adds learned position vectors; the original Transformer used sinusoidal encodings.

Learned absolute positions are bounded by the allocated context table. Sinusoidal and rotary approaches are alternatives with different behavior. Do not claim every modern LLM simply adds the same sinusoidal encoding.

07. The feed-forward network transforms each token

Timing: 12:00–14:00 (2 minutes).

Teaching intent: The same nonlinear MLP is applied independently at each position.

Attention mixes information between positions. The tokenwise MLP transforms features locally and adds nonlinearity. Our notebook uses GELU; the original 2017 formulation used ReLU.

15. Training is parallel across known positions

Timing: 28:00–30:00 (2 minutes).

Teaching intent: The causal mask permits computing many training losses together.

Parallel computation during teacher-forced training does not make arbitrary autoregressive generation parallel. During generation each next input depends on the token just produced. Cached states may reduce repeated work but do not remove that dependency.
