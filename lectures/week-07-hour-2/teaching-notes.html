02. One context can be a bottleneck

Timing: 02:00–04:00 (2 minutes).

Teaching intent: Different output positions may need different parts of the input.

In a classic sequence-to-sequence encoder-decoder, the final state must carry all useful source detail. Attention makes earlier states accessible for each decoder step. This is a capacity and routing motivation, not a theorem that every final-state model must fail.

05. Keep the full set of encoder states

Timing: 08:00–10:00 (2 minutes).

Teaching intent: The decoder can retrieve from H instead of using only the final state.

All encoder states form an addressable memory. The decoder query selects which states contribute for the current prediction. Access cost grows with memory length, and the states themselves remain learned representations.

10. Scaled dot products control score magnitude

Timing: 18:00–20:00 (2 minutes).

Teaching intent: Divide by √dₖ so high-dimensional dot products are less likely to saturate softmax.

Under independent zero-mean unit-variance coordinates the dot-product variance grows with d_k. Scaling reduces that variance. It is not cosine normalization and does not eliminate every saturation issue.

Timing: 20:00–22:00 (2 minutes).

Teaching intent: Normalize separately for each query over its available keys.

12. Retrieval is a weighted sum

Timing: 22:00–24:00 (2 minutes).

Teaching intent: Each value contributes according to its attention weight.

Weighted averaging combines values rather than selecting a single argmax key. The context width is d_v. With nonnegative normalized weights, the context lies in the convex hull of values before later projections and residual additions.

Timing: 38:00–40:00 (2 minutes).

21. Padding masks hide nonexistent tokens

Timing: 40:00–42:00 (2 minutes).

Teaching intent: Padding and causality enforce different constraints.

Padding marks filler positions that do not correspond to observations. A causal mask depends on relative positions. Their intersection defines available keys. Padded query outputs should be excluded from the training loss.

24. Dense attention has a quadratic score grid

Timing: 46:00–48:00 (2 minutes).

Teaching intent: Doubling context length quadruples score entries at fixed head count.

Count pairs rather than asserting all computation is quadratic: dense attention score interactions are O(T^2*d_k), while feed-forward cost also depends on width. Fused exact kernels can avoid materializing the whole score matrix, without changing dense pair count.

30. Exit: attention needs an architecture around it

Timing: 58:00–60:00 (2 minutes).

Teaching intent: Position information, nonlinear transformations, residual paths, and normalization complete the next story.

Use the exit prompt to bridge H3. Attention alone mixes representations, but sequence modeling also needs positional structure, a trainable block, an output objective, and evaluation. The next hour assembles and tests those pieces.

Expected answer: Its decoder can supply a query and retrieve from encoder states; attention does not require a Transformer.
