Learning path

From a loss function to a policy.

  1. Formulate the optimization problem

    Identify decision variables, an objective and constraints. Understand how the formulation determines what an optimal solution means.

  2. Use gradients, convexity and duality

    Study gradient-based methods, convexity and constrained optimization. Connect algorithmic updates with assumptions about the problem.

  3. Describe sequential decisions

    Use Markov decision processes, rewards and returns to distinguish one-step optimization from long-term decision-making.

  4. Learn values and policies

    Move from dynamic programming to model-free learning, then compare value-based and policy-based methods through Python implementations and simulation.

  5. Evaluate responsibly

    Explain the objective being optimized, the assumptions behind the environment and the limits of a learned decision rule.
