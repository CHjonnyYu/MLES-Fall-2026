Colab or local Jupyter

Start with a clean runtime.

  1. Click Open in Colab and save a copy to your own Drive.
  2. Use a CPU runtime, then run every cell from top to bottom.
  3. Read the Markdown explanation and predict the result before each operation.
  4. Download your evidence JSON and model artifacts before the runtime ends.

For local work: download the .ipynb, install Python and Jupyter, then run the setup cell. The setup installs missing free packages; all core data are generated locally or included with scikit-learn.
