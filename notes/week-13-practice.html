2. Build a small document corpus

Use six original teaching statements with stable IDs. Retrieval finds relevant text; it does not verify whether that text is true.

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
docs={"S1":"LSTM uses input forget and output gates to update memory.",
      "S2":"Causal attention masks future token positions before softmax.",
      "S3":"A chronological split prevents training on later target times.",
      "S4":"Precision divides true positives by predicted positives.",
      "S5":"Recall divides true positives by actual positives.",
      "S6":"A seed and data hash help reproduce an experiment."}
vectorizer=TfidfVectorizer().fit(list(docs.values()))
matrix=vectorizer.transform(list(docs.values()))

Checkpoint. Document IDs are provenance anchors, not evidence that an LLM has cited faithfully.

3. Retrieve with a similarity threshold

Define an abstention rule when every similarity is zero. TF-IDF is a lexical baseline and can miss paraphrases.

def retrieve(query):
    scores=cosine_similarity(vectorizer.transform([query]),matrix)[0]
    if scores.max()<=0: return {"status":"abstain","sources":[]}
    order=scores.argsort()[::-1][:2]
    return {"status":"retrieved","sources":[{"id":list(docs)[i],"text":list(docs.values())[i],"score":float(scores[i])} for i in order if scores[i]>0]}
answer=retrieve("How does causal attention hide future positions?")
print(json.dumps(answer,indent=2))

Checkpoint. The causal attention statement should rank highly. Similarity is not a confidence probability.

4. Test retrieval and abstention separately

One unit test expects a source ID and another expects no answer. This example returns extracted evidence, not model-generated prose.

assert retrieve("causal attention future")["sources"][0]["id"]=="S2"
assert retrieve("zirconium spectroscopy")["status"]=="abstain"
summary={"retrieval":answer,"abstention":retrieve("zirconium spectroscopy"),"generator":"none; extractive teaching baseline"}
print(summary["abstention"])
