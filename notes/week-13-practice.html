Week 13: Retrieval, source evidence, and structured knowledge

WEEK 13 / 2026-11-30 / MONDAY 14:00-17:00

Build a lexical retrieval baseline; measure retrieval separately from grounded claim support; abstain without evidence.

Use original fictional lab passages and independently labeled questions. This lexical retrieval and extractive evidence workflow does not call a generative model; it is a baseline for, not a full implementation of, RAG.

60 minutes explanation + 120 minutes practice. Eight core exercises and two optional challenges. No additional weekly graded homework, API key, paid model inference or GPU required.

Represent documents and retrieve evidence

Retrieval selects evidence, not truth

Find relevant passages before composing a source-bounded response.

Worked reasoning: Document identity; lexical vectors; cosine similarity; ranking; threshold; Task 1 and Task 2.

Can the best-ranked passage be wrong?

Yes. Ranking measures a chosen similarity, not the authority or factual correctness of a source.

Document identity must survive chunking

Store source ID, version and chunk location with every passage.

Worked reasoning: LAB-02:v1:chunk0 identifies an original teaching protocol passage; it is not an external scientific publication.

What breaks when IDs are just row positions?

Inserting a passage changes positional identities. Use stable source keys and preserve the indexed text snapshot.

Tokenization defines lexical overlap

A vocabulary maps terms to coordinates; preprocessing changes what matches.

Worked reasoning: Vocabulary [heat,limit,mean]; document 'heat heat limit' maps to [2,1,0].

Does this representation preserve word order?

No. Bag-of-words counts lose order; negation and relational meaning can be missed.

IDF discounts corpus-common terms

Smoothed IDF is ln((1+N)/(1+df))+1 in this notebook.

Worked reasoning: N=4, df=1 gives ln(5/2)+1=1.916; df=4 gives 1.0.

Is a rare term necessarily an important fact?

No. IDF is a statistical corpus weight. Rare typos and irrelevant words can also receive large weights.

TF-IDF is a fitted representation

Fit the vectorizer on the frozen corpus; transform questions with it.

Worked reasoning: The same query should be scored against one fixed index. New documents require an explicit index version.

What happens to unseen query words?

They do not create new fitted coordinates. A fully out-of-vocabulary query gives a zero vector under this baseline.

Cosine compares directions

Normalize vectors before using their dot product as similarity.

Worked reasoning: q=[1,1], d=[2,0]; cosine=2/(sqrt(2)*2)=0.707.

Is cosine a probability that the passage is correct?

No. It is a geometric similarity under the representation. A threshold is an operating rule, not calibrated confidence.

Top-k is a selection rule

Rank descending; break equal-score ties with stable source IDs.

Worked reasoning: If scores are equal, sort document IDs lexically so the same snapshot returns the same order.

Can a deterministic tie rule improve relevance?

Not inherently. It improves reproducibility and makes ambiguous rankings visible.

Thresholds trade coverage and abstention

Return no evidence when the maximum score is below a declared threshold.

Worked reasoning: Use an in-vocabulary protocol question and an unrelated vocabulary question. Inspect full score vectors.

Does a low score prove the answer does not exist?

No. Lexical mismatch can hide a relevant passage. Abstention is a limitation-aware action, not a proof of absence.

Chunking can remove required context

A passage without its units or exception can support the wrong claim.

Worked reasoning: Compare 'review if mean at least 80 C' with a chunk containing only 'review if mean at least 80'.

Why is the shorter chunk risky?

The missing unit changes interpretation, and retrieval alone cannot recover a qualifier absent from the supplied passage.

Summary: freeze the representation

Preserve corpus, source IDs, vectorizer configuration and ranking rule.

Worked reasoning: Show the exact quote, score and source version. Explain one lexical retrieval limitation.

What will the next hour add?

Independent relevance labels and claim-support checks. A retrieved citation is not yet a verified answer.

Measure retrieval and check claim support

Two evaluation layers answer different questions

Retrieval asks whether evidence was found; grounding asks whether a claim follows.

Worked reasoning: A relevant passage can be retrieved while the answer misstates its threshold.

Can perfect retrieval recall guarantee a correct response?

No. Generation, interpretation and citation entailment can fail after retrieval succeeds.

Recall at k needs a relevance set

Recall@k = retrieved relevant sources / all labeled relevant sources.

Worked reasoning: Relevant={A,B}; top2={A,C}; recall@2=1/2. Precision@2=1/2.

What if no relevant source is labeled?

Do not divide by zero or fabricate relevance. Evaluate no-evidence/abstention cases separately.

Reciprocal rank rewards the first hit

For an answerable query, RR = 1/rank of the first relevant result.

Worked reasoning: [C,A,B] and [A,C,B] may have the same recall@3 but different reciprocal rank.

Why report the rank convention?

Metrics depend on k, relevance labels, tie rules and zero-hit handling. Preserve these definitions with the result.

An evidence quote has a narrow role

An exact substring proves text location, not whether every derived claim follows.

Worked reasoning: Source: threshold 80 C. Claim: threshold 95 C. A correct source ID does not rescue the wrong number.

What does automatic quote containment miss?

It misses paraphrase meaning, omitted exceptions and contradictions. Human or task-specific semantic checks remain necessary.

Task 3: score fixed retrieval questions

Use independently written relevance IDs; do not derive labels from ranking.

Worked reasoning: Compute macro recall only across answerable queries; list no-evidence outcomes separately.

Why not label the top result as relevant?

That would make the system grade itself and conceal retrieval failures.

Task 4: inspect false support

Test wrong citation IDs, fabricated quotes and changed numeric thresholds.

Worked reasoning: Unknown source; absent quote; quoted text with a contradictory threshold. They require different diagnoses.

Will string checks catch every wrong claim?

No. They are necessary structural checks in this exercise, not a universal entailment detector.

Task 5: change k under a fixed index

Keep questions, labels and threshold fixed while varying k.

Worked reasoning: Recall cannot decrease when adding ranked results under the same accepted query; precision can decrease.

Why can a threshold obscure that comparison?

A changed threshold changes which results are eligible. Keep it fixed and report abstention separately.

Treat source instructions as data

A malicious sentence in a passage cannot alter tool permissions.

Worked reasoning: The corpus includes an explicitly marked untrusted instruction. Retrieval may return it, but the workflow never executes it.

Does a low similarity score secure a RAG system?

No. Relevant malicious text can rank highly. Security enforcement must not depend on the retriever missing it.

Structured knowledge needs provenance too

A table row should retain units, source ID, version and extraction status.

Worked reasoning: name=review threshold; value=80; unit=C; source=LAB-02:v1; status=teaching fixture.

Why not call this a validated engineering limit?

It is an original fictional class protocol. It has no external safety authority or hardware validation.

Summary: evidence retrieval precedes explanation

Find a passage, preserve its identity, then check what it actually supports.

Worked reasoning: Save ranked IDs, scores, labels and one support failure. Do not export a bare average.

What should a partner be able to reconstruct?

Which question, index snapshot, ranking and relevance labels produced each reported metric.

Retrieval studio: diagnose and package failures

Build an evidence-first retrieval record

Complete eight core tasks, then preserve an honest failure.

Worked reasoning: Restore 5 min; tasks 25 min; source audit 15 min; export and explain-back 15 min.

What is the artifact, not just the score?

A corpus snapshot, ranking configuration, per-query records, response fields, figures and hashes.

Task 1: distinguish answerable and unknown

Inspect the maximum cosine and abstention status for both questions.

Worked reasoning: The system returns no evidence instead of inventing a threshold or citation.

What does the abstention support?

Only that this index and operating rule supplied no accepted passage for this query.

Task 2: explain one weighted term

Compare term frequency, document frequency and IDF contribution.

Worked reasoning: An IDF of 1.0 is not zero; the default smoothed formula retains corpus-common terms.

What changes if the corpus changes?

Vocabulary, document frequencies, IDF, norms and rankings may all change. Preserve an index version.

Task 3: compute macro retrieval recall

Calculate per-query recall before averaging answerable cases.

Worked reasoning: Two queries with one and two relevant documents each receive equal weight under macro averaging.

Is macro recall the same as pooled recall?

Not generally. Pooled recall weights by the number of relevant documents. Name the aggregation you use.

Task 4: find a citation failure

Compare a truthful quote with a wrong-threshold claim.

Worked reasoning: Do not say only 'bad citation'. Identify the changed number, missing unit or absent quote.

Can an automatic pass replace source reading?

No. The class checks exact fields and narrow numeric facts; general semantic support remains a separate review.

Task 5: vary k without tuning on the final set

Use development questions for exploration; preserve held-out questions.

Worked reasoning: Record k and threshold before examining the held-out results. If already seen, label further work exploratory.

What makes a final report optimistic?

Repeatedly changing retrieval settings after seeing held-out outcomes and reporting only the best score.

Task 6: add a genuinely independent query

Write its relevant IDs before execution and justify them from source text.

Worked reasoning: Try a paraphrase to expose lexical mismatch. Explain whether a miss is due to wording or missing corpus evidence.

Is one new query a representative benchmark?

No. It is a diagnostic probe. Broader coverage requires a task-based question set.

Task 7: separate tool results from passages

A computed mean is not a retrieved protocol threshold.

Worked reasoning: Mean 81 C is computed from readings; threshold 80 C comes from the fictional protocol; comparison requests review.

What remains outside this exercise?

Physical measurement validity, real safety limits, automatic control authority and external deployment validation.

Task 8: export source-bounded evidence

Keep corpus hash and exact retrieved text with the metric table.

Worked reasoning: They select a query, locate its IDs and quotes, and reproduce its recall from the labeled relevant set.

Why preserve text as well as a link?

Sources and chunks can change. A frozen snapshot makes the reported computation inspectable.

Summary: ask what the source entails

Optional A changes chunking; optional B adds an adversarial passage.

Worked reasoning: Explain each outcome using a specific source or absent source, not a vague model-confidence story.

What connects to the next week?

The same untrusted evidence must pass through explicit permissions, budgets and approval gates before any action.
