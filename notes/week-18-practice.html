2. Reconstruct the attention calculation

Solve before running: scores [1,0,1]/sqrt(2), values [[10,0],[0,10],[10,10]].

scores=np.array([1.,0.,1.])/np.sqrt(2)
weights=np.exp(scores-scores.max()); weights/=weights.sum()
values=np.array([[10.,0.],[0.,10.],[10.,10.]])
context=weights@values
print("Weights:",weights,"Context:",context)
assert np.isclose(weights.sum(),1)

Checkpoint. You should explain scores, softmax, and weighted retrieval as three distinct operations.

3. Distinguish a model from an agent

Sort components by their role. This small schema is a rehearsal aid, not a grading rubric.

components={"predictor":"maps input tokens to next-token logits",
            "tool":"executes a validated operation",
            "controller":"chooses or validates the next bounded step",
            "evidence":"records inputs, outputs, configuration and checks",
            "human":"authorizes consequential actions and judges limits"}
for name,role in components.items(): print(name+": "+role)

Checkpoint. A Transformer supplies a model component; it does not by itself define permissions or an execution loop.
