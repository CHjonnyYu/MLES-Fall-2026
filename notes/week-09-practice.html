2. Build a controlled held-out experiment

We deliberately train and test on a known synthetic relation. Later we change one feature distribution to study sensitivity.

from sklearn.model_selection import train_test_split
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error
X=rng.normal(size=(500,3)); y=2*X[:,0]+X[:,1]**2+rng.normal(0,.2,500)
Xtr,Xte,ytr,yte=train_test_split(X,y,test_size=.3,random_state=SEED)
model=Ridge().fit(Xtr,ytr)
residual=model.predict(Xte)-yte

Checkpoint. The linear model cannot represent the quadratic term exactly. This is an inspectable model-class limitation.

3. Inspect subgroup errors

Define subgroups using a feature range before inspecting outcomes. Error differences can reveal where the model specification fails.

extreme=np.abs(Xte[:,1])>1
summary={"overall_MAE":float(np.mean(np.abs(residual))),
         "extreme_MAE":float(np.mean(np.abs(residual[extreme]))),
         "ordinary_MAE":float(np.mean(np.abs(residual[~extreme])))}
print(summary)
plt.scatter(Xte[:,1],residual); plt.axhline(0,color="black")
plt.xlabel("Feature 1"); plt.ylabel("Residual"); plt.show()

Checkpoint. Do not report only the overall metric when a subgroup fails systematically.

4. Stress-test a changed population

Generate a second population with wider feature 1 values and the same underlying formula. Keep the trained model fixed.

shifted=rng.normal(size=(150,3)); shifted[:,1]*=2.5
shifted_y=2*shifted[:,0]+shifted[:,1]**2+rng.normal(0,.2,150)
summary["shifted_MAE"]=float(mean_absolute_error(shifted_y,model.predict(shifted)))
print(summary)

Checkpoint. This synthetic stress test isolates one failure mechanism. It does not quantify every real deployment shift.
