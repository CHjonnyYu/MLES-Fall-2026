Vary the cluster count

Fit k=2,3,4 using training features only, and inspect test-space silhouette scores. Treat this as exploratory representation analysis, not supervised class recovery.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
observations['task2']=[]
for k_demo in [2,3,4]:
    fitted=KMeans(n_clusters=k_demo,n_init=10,random_state=2026).fit(Ztr)
    assigned=fitted.predict(Zte)
    observations['task2'].append({'k':k_demo,'silhouette':float(silhouette_score(Zte,assigned))})
print(observations['task2'])

Self-check: Report actual scores. A larger silhouette is evidence about separation in this representation, not proof of meaningful physical categories.
