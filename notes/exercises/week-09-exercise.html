What this lesson lets you explain

A test average can hide a weak group. A residual pattern can suggest a missing feature. An input change differs from a changed target relationship. A function explanation can be checked numerically. Saved evidence supports only the replay scope actually tested.

Troubleshooting

  • NameError: restart and run from Setup in numeric order.
  • A failed assertion: keep the failure, identify which invariant changed and restore the declared baseline before changing one factor.
  • Missing chart: wait for the corresponding code cell to finish; all figures are also inside the evidence ZIP.
  • Different values after editing: preserve your changes and compare configuration, split and data hash. Do not replace a failed run with a copied score.
  • Colab download: Files sidebar → week09-evidence.zip → Download. Save the edited notebook separately.
