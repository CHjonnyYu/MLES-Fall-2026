TASK 2 / PREDICT - RUN - EXPLAIN

Expose a misleading passing case

Compare zero-sum and negative-mean cases. Explain why passing one symmetric case can hide a denominator bug.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
observations['task2']=[]
for values_ex in [[-2,2],[-2,-4],[5]]:
    observations['task2'].append({'values':values_ex,'expected':float(np.mean(values_ex)),'candidate':float(buggy_candidate(values_ex))})
print(observations['task2'])

Self-check: The zero-sum case can pass despite the bug. At least one nonzero-mean case is needed to expose the failure.

TASK 3 / PREDICT - RUN - EXPLAIN

Declare a numerical tolerance

Compare two close values under two tolerances, and explain the difference between absolute and relative error.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
expected_ex=1.; observed_ex=1.+1e-7
observations['task3']={str(tol):bool(np.isclose(observed_ex,expected_ex,atol=tol,rtol=0)) for tol in [1e-6,1e-9]}
print(observations['task3'])

Self-check: The comparison passes at absolute tolerance 1e-6 but fails at 1e-9. A tolerance must be justified before interpreting pass rates.
