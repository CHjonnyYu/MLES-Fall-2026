CORE TASK 5 / PREDICT - RUN - EXPLAIN

Task 5. Inspect required rejections separately

Count valid and invalid fixtures explicitly, and check the same component rules for both candidates.

groups={}
for name,rows in evaluations.items():
    groups[name]={}
    for group,subset in [('valid',[r for r in rows if r['expected']['status']!='rejected']),('invalid',[r for r in rows if r['expected']['status']=='rejected'])]:
        groups[name][group]={'n':len(subset),'passed':sum(r['passed'] for r in subset)}
assert groups['reference']['invalid']['passed']==groups['reference']['invalid']['n']
observations['task5']={'groups':groups,'sampling_limit':'Designed nonrandom synthetic fixtures; no population confidence interval claimed.'}
print(groups)

Self-check: The case, not each repeated reading, is the evaluation unit. Show counts alongside every percentage.

CORE TASK 8 / PREDICT - RUN - EXPLAIN

Task 8. Export rows, not only averages

Save a CSV with defined numeric fields and explicit unavailable values for required rejection cases.

import csv
save_json('evaluation.json',evaluations); save_json('release.json',gates)
with (ARTIFACTS/'per-case.csv').open('w',newline='') as f:
    writer=csv.DictWriter(f,fieldnames=['candidate','case_id','passed','status_ok','mean_abs_error_C']); writer.writeheader()
    for name,rows in evaluations.items():
        for r in rows: writer.writerow(dict(candidate=name,**{k:r[k] for k in ['case_id','passed','status_ok','mean_abs_error_C']}))
