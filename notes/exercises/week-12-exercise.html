Before you start

  1. Use a CPU runtime. Save a personal copy or open the downloaded notebook in Jupyter.

TASK 1 / PREDICT - RUN - EXPLAIN

Keep unsupported tools disabled

Send a valid mean request and an unsupported delete_files request to the deterministic teaching controller. Explain which layer refuses the unsupported action.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
observations['task1']={'allowed':run_request({'tool':'mean','values':[1,2,3]}),'blocked':run_request({'tool':'delete_files','values':[1,2,3]})}
print(observations['task1'])

Self-check: The mean is 2. The unsupported action must be refused, not executed. No real file deletion or model API is involved.
