Keep raw measurements unchanged

Predict the replacement for the missing temperature. Run the cell, then replace 27 with 270 and rerun. Explain why the cleaning rule must be recorded rather than silently changing raw data.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
raw_demo=np.array([[1.,25.,50.],[2.,np.nan,52.],[3.,27.,54.]])
clean_demo=raw_demo.copy()
fill_value=float(np.nanmedian(raw_demo[:,1]))
clean_demo[np.isnan(clean_demo[:,1]),1]=fill_value
observations['task1']={'fill_value':fill_value,'raw_missing':int(np.isnan(raw_demo).sum()),'clean_missing':int(np.isnan(clean_demo).sum())}
print(observations['task1'])

Self-check: With the original values, the median is 26. The raw table still has one missing value; the cleaned table has none.

TASK 2 / PREDICT - RUN - EXPLAIN

Identify data without claiming authenticity

Hash the original and cleaned tables. Predict whether the hashes match. Change one measurement and explain what a changed hash does and does not establish.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
raw_digest=hashlib.sha256(raw_demo.tobytes()).hexdigest()
clean_digest=hashlib.sha256(clean_demo.tobytes()).hexdigest()
observations['task2']={'raw_sha256':raw_digest,'clean_sha256':clean_digest,'same_bytes':raw_digest==clean_digest}
print(observations['task2'])

Self-check: The hashes differ. A hash identifies bytes; it does not prove that a measurement is genuine.

Separate identifiers from measurements

renumbered=clean_demo.copy(); renumbered[:,0]=[30,10,20]
