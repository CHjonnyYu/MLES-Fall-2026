TASK 1 / PREDICT - RUN - EXPLAIN

Preserve bytes and interpretation

Hash the saved bytes of a tiny array, restore it, and keep a schema. Explain why a hash alone is not enough to interpret an artifact.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
import io
buffer_ex=io.BytesIO(); np.save(buffer_ex,np.array([1.,2.,3.]))
payload_ex=buffer_ex.getvalue(); restored_ex=np.load(io.BytesIO(payload_ex))
observations['task1']={'sha256':hashlib.sha256(payload_ex).hexdigest(),'restored_values':restored_ex.tolist(),'schema':{'quantity':'synthetic reading','unit':'synthetic units','shape':[3]}}
print(observations['task1'])

Self-check: The restored values are [1,2,3]. Interpretation requires quantities, units, shape, and a declared source in addition to byte identity.

Distinguish sample and population claims

Generate a finite sample from a zero-mean process. Change the seed and explain why the observed sample mean need not be exactly zero.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
sample_ex=np.random.default_rng(2026).normal(size=100)
observations['task2']={'seed':2026,'sample_size':len(sample_ex),'observed_mean':float(sample_ex.mean()),'population_expectation':0.}
print(observations['task2'])

Self-check: Report the observed sample mean. Do not replace an observed result with the population expectation.

Completion checklist

  • Three predictions and three explanations.
  • One controlled change with its actual outcome.
  • One limitation and a brief AI-use/checking disclosure, or "none".

The notebook marks incomplete response records as drafts. Completing the fields is not proof that an explanation is correct.
