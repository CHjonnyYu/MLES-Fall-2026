How to work independently

  1. Open the notebook in Colab or Jupyter using a CPU runtime.
  2. Run environment and reference mechanism cells in order.
  3. Before each analysis cell, fill the prediction field; afterward explain one actual value or failure.

  5. Export and download the evidence ZIP before the temporary runtime ends. Save your own edited notebook too.

CORE TASK 2 / PREDICT - RUN - EXPLAIN

Task 2. Check identity before numeric values

Reverse a copied result list, detect a sequence mismatch, then align explicitly by unique stable IDs.

reordered=list(reversed(REFERENCE)); expected_ids=[r['case_id'] for r in REFERENCE]; got_ids=[r['case_id'] for r in reordered]
assert got_ids!=expected_ids
lookup={r['case_id']:r for r in reordered}; assert len(lookup)==len(REFERENCE) and set(lookup)==set(expected_ids)
aligned=[lookup[k] for k in expected_ids]
assert [r['mean_C'] for r in aligned]==[r['mean_C'] for r in REFERENCE]
observations['task2']={'expected_ids':expected_ids,'reordered_ids':got_ids,'aligned_ids':[r['case_id'] for r in aligned]}; print(observations['task2'])

Self-check: A length match or aggregate score is not an ID alignment check. Explicitly reject missing or duplicate IDs.

CORE TASK 4 / PREDICT - RUN - EXPLAIN

Task 4. Extract a whitelisted handover ZIP

Inspect each archive member and its manifest before execution. The supplied extractor accepts exactly six known base names.

handover_zip=ARTIFACTS/'handover.zip'
with zipfile.ZipFile(handover_zip,'w',zipfile.ZIP_DEFLATED) as z:
    for name in sorted(REQUIRED|{'manifest.json'}): z.write(BUNDLE/name,arcname=name)
EXTRACTED=Path(tempfile.mkdtemp(prefix='mles-w17-extracted-'))
with zipfile.ZipFile(handover_zip) as z:
    assert z.testzip() is None
    names=z.namelist()
    if len(names)!=len(set(names)) or set(names)!=(REQUIRED|{'manifest.json'}): raise ValueError('unexpected archive members')
    for name in names:
        if Path(name).name!=name: raise ValueError('unsafe archive path')
    z.extractall(EXTRACTED)
assert verify_bundle(EXTRACTED)
observations['task4']={'archive_members':sorted(names),'verified':True,'scope':'Only reviewed local fixture source; do not execute arbitrary received Python.'}; print(observations['task4'])

Self-check: A ZIP CRC check establishes readable archive storage, not code safety. Source review remains required.

CORE TASK 6 / PREDICT - RUN - EXPLAIN

Task 6. Compare aligned numeric outputs

Check exact ID sequence and status first. Then apply the frozen absolute-plus-relative numeric tolerance.

assert [r['case_id'] for r in replay['results']]==[r['case_id'] for r in REFERENCE]
differences=[]
for actual,expected in zip(replay['results'],REFERENCE):
    assert actual['status']==expected['status']
    for field in ['mean_C','sample_sd_C']:
        assert math.isclose(actual[field],expected[field],abs_tol=CONFIG['atol'],rel_tol=CONFIG['rtol'])
    differences.append(actual['mean_C']-expected['mean_C'])
observations['task6']={'mean_differences_C':differences,'max_abs_mean_difference_C':max(map(abs,differences)),'comparison':CONFIG}
plot('replay-differences.png',[r['case_id'] for r in REFERENCE],differences,'Replay minus reference mean (C)','Computational agreement, not physical prediction error')
print(observations['task6'])

Self-check: Zero replay difference does not establish physical accuracy. The original workflow can be reproduced even when its scientific assumptions are wrong.

CORE TASK 7 / PREDICT - RUN - EXPLAIN

Task 7. Detect tampering on a copy

Append bytes to a copied request payload. Verify the reference copy is unchanged and the copied bundle is rejected.

with tempfile.TemporaryDirectory() as td:
    copied=Path(td)/'altered'; shutil.copytree(BUNDLE,copied)
    with (copied/'request.json').open('a') as f: f.write('\n')
    try: verify_bundle(copied)
    except ValueError as e: message=str(e)
    else: raise AssertionError('Tampered bundle unexpectedly accepted')
    assert 'checksum mismatch' in message
assert verify_bundle(BUNDLE)
observations['task7']={'tamper_rejected':True,'message':message,'original_verified':True,'limit':'Unsigned manifest checks integrity, not sender authenticity.'}
print(observations['task7'])

Self-check: This change can preserve parsed values while changing bytes. A sender replacing both payload and manifest remains outside this integrity check.
