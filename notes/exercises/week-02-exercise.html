from sklearn.preprocessing import StandardScaler
train_demo=np.array([[1.],[2.],[3.]])
test_demo=np.array([[100.],[120.]])
safe_scaler=StandardScaler().fit(train_demo)
leaky_scaler=StandardScaler().fit(np.vstack([train_demo,test_demo]))
observations['task1']={'training_mean':float(safe_scaler.mean_[0]),'leaky_mean':float(leaky_scaler.mean_[0])}
print(observations['task1'])

Self-check: The safe mean stays 2 when only test values change. The leaky mean changes.

TASK 3 / PREDICT - RUN - EXPLAIN

Preserve feature order and units

Train the small pipeline below. Compare normal test features with reversed feature columns. Explain why matching array shape is not enough.

  1. Write your prediction in the notebook response field before running.
  2. Run the starter cell below after the worked walkthrough.
  3. Make the requested controlled change and record the configuration.
  4. Explain the mechanism using the actual output, not an invented result.
from sklearn.datasets import load_iris
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LogisticRegression
iris_demo=load_iris()
ix_train,ix_test=train_test_split(np.arange(len(iris_demo.target)),test_size=.25,stratify=iris_demo.target,random_state=2026)
feature_model=make_pipeline(StandardScaler(),LogisticRegression(max_iter=300)).fit(iris_demo.data[ix_train],iris_demo.target[ix_train])
p1=feature_model.predict(iris_demo.data[ix_test]); p2=feature_model.predict(iris_demo.data[ix_test,::-1])
observations['task3']={'changed_predictions':int(np.sum(p1!=p2)),'feature_names':iris_demo.feature_names}
print(observations['task3'])

Self-check: Report the observed number of changed predictions. Reversing columns changes feature meaning even when the shape is identical.
